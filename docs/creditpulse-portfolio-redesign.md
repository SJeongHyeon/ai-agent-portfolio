# CreditPulse 포트폴리오 개편 설계

기준: 공개 포트폴리오 저장소 main의 8f9cea2 (2026-11-19 확인). 대상은 채용 담당자와 AI 엔지니어 기술 면접관이다.

## 목적
최근 완성한 CreditPulse를 대표 프로젝트로 추가하고, 세 팀 프로젝트에서 실제로 만든 기술과 검증 근거를 한 흐름에서 읽게 한다. 개인 기여와 팀 성과, 평가 조건과 운영 현황을 구분한다.

## 진행 순서
1. 현행 프로젝트 데이터·상세·도슨트에 CreditPulse를 추가한다.
2. 첫 화면을 개인의 구현·검증 방식 중심으로 바꾸고, 세 프로젝트를 같은 위계로 보여 준 뒤 기술별 근거를 연결한다. 학습 프로젝트는 별도 작은 영역에 둔다.

## 고려한 구성
- 현행 두 카드에 하나만 추가: 변경이 작지만 첫 화면과 역량 설명에 최신 작업이 빠진다.
- 기술별 목록만 앞세우기: 면접관에게 유용하나 채용 담당자가 서비스를 빠르게 이해하기 어렵다.
- 선택: 프로젝트를 먼저 보여주고 기술을 사례에 연결. CreditPulse를 첫 사례로 배치하지만 세 프로젝트의 카드와 첫 화면 링크는 같은 위계로 보여 준다.

## 내용·제약
흑백 스타일과 정적 HTML/CSS/JS를 유지한다. CreditPulse는 공개 사본과 데모 영상으로 연결한다. 23/25는 동결 평가셋 v2 관련 25문항을 2026-11-12 한 번 실행한 값으로만 쓴다. 그래프 검색과 목차 어휘 번역은 미채택이라고 명시한다. 외부 API 호출과 새 의존성은 없다. 초기 설계에서는 게시를 제외했으나, 사용자 후속 요청에 따라 기존 Vercel 사이트에 배포하고 반영 결과를 확인한다. PR은 생성하지 않는다.

## 성공 기준
프로젝트 카드와 상세가 3개이고 링크가 각각 맞는다. 첫 화면과 기술 설명이 세 프로젝트에 연결된다. 안내 도슨트가 CreditPulse 질문에 답한다. 링크·문구·모바일 배치를 확인하고 npm test, git diff --check를 통과한다.
